# AI Builder — منصة بناء المواقع والتطبيقات بالذكاء الاصطناعي

منصة عربية RTL لإنشاء مشاريع ويب بمساعدة نماذج الذكاء الاصطناعي، مع معاينة وإدارة مشاريع وإعدادات مزودي الذكاء الاصطناعي.

> الحالة: أساس أولي قيد التطوير، وليس منصة إنتاج مكتملة بعد. لا تضع مفاتيح حقيقية في GitHub.

## المتطلبات
- Node.js 22+
- npm
- مفتاح API من مزود متوافق عند استخدام التوليد

## التشغيل المحلي
```bash
cp .env.example .env.local
npm install
npm run dev
```
افتح `http://localhost:3000`.

## الإعدادات والأسرار
- تُحفظ المفاتيح في متغيرات البيئة على الخادم فقط.
- لا تستخدم `NEXT_PUBLIC_` لمفاتيح API.
- لا ترفع `.env.local` أو مفاتيح حقيقية إلى Git.
- إعداد لوحة لإدارة الأسرار المشفرة يحتاج إلى مصادقة وتخزين آمنين قبل تفعيله في الإنتاج.

## النشر
اربط المستودع بمزود استضافة يدعم Next.js، واضبط متغيرات البيئة من إعدادات الاستضافة. اختبر البناء قبل توجيه نطاق الإنتاج.

## خارطة الطريق
1. واجهة عربية ولوحة مشاريع.
2. واجهة موحدة لمزودي الذكاء الاصطناعي مع فحص المدخلات والأخطاء.
3. توليد ملفات مشروع قابلة للتنزيل ومعاينة آمنة معزولة.
4. مصادقة وتخزين مشاريع وقواعد بيانات.
5. نشر آمن لكل مشروع مع سجلات ومراقبة.

## الأمان
تشغيل كود مولّد من المستخدمين يتطلب بيئة sandbox معزولة وحدود موارد. لا تنفّذ كودًا مولدًا داخل عملية المنصة أو على الخادم الرئيسي.
