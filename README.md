# AI Builder — منصة بناء المواقع والتطبيقات بالذكاء الاصطناعي

واجهة عربية RTL لتوليد نموذج ويب أولي عبر مزود ذكاء اصطناعي، مع تنزيل HTML.

## التشغيل
يتطلب Node.js 22+:
```bash
cp .env.example .env.local
npm install
npm run dev
```
ثم افتح http://localhost:3000.

## تفعيل التوليد
اضبط AI_PROVIDER على openai أو anthropic أو google، ثم أضف المفتاح الموافق في بيئة الخادم. أسماء المتغيرات موجودة في .env.example. لا تستخدم NEXT_PUBLIC_* للأسرار ولا ترفع .env.local إلى GitHub.

## ما يعمل في هذا الإصدار
- واجهة عربية متجاوبة.
- مسار خادمي /api/generate عبر AI SDK.
- التحقق من المدخلات ورسائل أخطاء لا تكشف المفتاح.
- فحوص حجم الطلب ومصدر المتصفح وحدّ طلبات مؤقت على مستوى العملية.
- تنزيل كتلة HTML المولدة كملف.

## حدود مهمة
هذا إصدار أولي لتوليد نموذج HTML واحد، وليس منشئ تطبيقات كاملًا: لا توجد مصادقة أو حفظ مشاريع أو قاعدة بيانات أو تشغيل آمن للكود أو نشر تلقائي للمشاريع المولدة. حدّ الطلبات الحالي محلي لكل عملية فقط وقد لا يحمي تطبيقًا موزعًا أو serverless؛ أضف محدد طلبات مشتركًا مثل Redis أو حماية على مستوى الاستضافة قبل إتاحة الخدمة للعامة. افحص HTML المولد قبل فتحه أو نشره.

## النشر
اربط المستودع بمضيف يدعم Next.js واضبط متغيرات البيئة من لوحة الاستضافة. لا تضع مفاتيح API في المستودع أو ملفات العميل.
