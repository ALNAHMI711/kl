# AI Builder — منصة بناء المواقع والتطبيقات بالذكاء الاصطناعي

واجهة عربية RTL لتوليد نماذج ويب ومشاريع أولية متعددة الملفات عبر مزود ذكاء اصطناعي.

## التشغيل
يتطلب Node.js 22+:
```bash
cp .env.example .env.local
npm install
npm run dev
```
ثم افتح http://localhost:3000.

## تفعيل التوليد
اضبط `AI_PROVIDER` على `openai` أو `anthropic` أو `google`، ثم أضف المفتاح الموافق في بيئة الخادم. أسماء المتغيرات موجودة في `.env.example`. لا تستخدم `NEXT_PUBLIC_*` للأسرار ولا ترفع `.env.local` إلى GitHub.

## ما يعمل في هذا الإصدار
- واجهة عربية متجاوبة.
- مسار خادمي `/api/generate` لتوليد نموذج HTML واحد وتنزيله.
- مسار `/api/generate-project` لتوليد ملفات أولية متعددة لمشروع Vite + React + TypeScript.
- فحوص لمسارات الملفات المولدة لمنع المسارات المطلقة و`..` والشرطات العكسية، مع حدود لعدد الملفات وحجم كل ملف والحجم الإجمالي.
- فحص `package.json` المولد ورفض سكربتات دورة حياة npm وسكربتات `pre*` و`post*` لتقليل تنفيذ أوامر تلقائية عند تثبيت التبعيات أو تشغيل أوامر المشروع.
- تنزيل ملفات المشروع المتعددة كأرشيف ZIP وعرض محتوى كل ملف في الواجهة.
- فحوص حجم الطلب ومصدر المتصفح وحدّ طلبات مؤقت على مستوى العملية.
- مفاتيح المزود تبقى على الخادم ورسائل الأخطاء لا تعرض الأسرار.

## حدود مهمة
هذه نسخة MVP وليست منشئ تطبيقات متكاملًا بعد. تُنزّل الملفات المولدة في أرشيف ZIP، لكن ذلك لا يعني أن المشروع اجتاز البناء أو الاختبارات أو المراجعة الأمنية. لا توجد حتى الآن مصادقة أو حفظ مشاريع في قاعدة بيانات أو معاينة معزولة أو تشغيل آمن للكود أو نشر تلقائي. لا تفتح أو تشغّل الملفات المولدة قبل مراجعتها. فحص سكربتات npm دفاع إضافي وليس ضمانًا بأن محتوى JavaScript أو التبعيات آمنة.

محددات الطلبات الحالية محلية لكل عملية فقط، وقد لا تحمي تطبيقًا موزعًا أو serverless. عند `TRUST_PROXY_HEADERS=false` يستخدم المساران مفتاحًا احتياطيًا واحدًا، لذلك تتشارك كل الزيارات حد الطلبات على نفس العملية وقد يتأثر المستخدمون ببعضهم؛ هذا سلوك محافظ وليس تحديدًا عادلًا لكل مستخدم. لا تفعّل `TRUST_PROXY_HEADERS=true` إلا إذا كان وكيل موثوق يزيل الرؤوس الواردة من العميل ويكتب `x-real-ip` أو `x-forwarded-for` بنفسه. قبل إتاحة الخدمة للعامة، استخدم محدد طلبات مشتركًا مثل Redis أو حماية على مستوى الاستضافة، واضبط هوية العميل من إعداد موثوق. لا تعتمد على رؤوس IP التي يرسلها العميل مباشرة.

## النشر
اربط المستودع بمضيف يدعم Next.js واضبط متغيرات البيئة من لوحة الاستضافة. لا تضع مفاتيح API في المستودع أو ملفات العميل.
